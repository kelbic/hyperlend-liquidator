# Реестр откатов (hyperlend-liquidator)

Каждая боевая правка обязана иметь однострочный откат. Формат: что включено → как откатить.
Все флаги — env (`~/.hyperlend-bot/env`) + рестарт (kill PID из `bot.pid.txt`, cron поднимет ≤60с).

## Ярус 1 гонки (04.08, GO владельца)

| Что | Флаг вкл. (деф.) | Откат | Прежнее поведение |
|---|---|---|---|
| Keep-alive HTTP-пул (read+write) | `HL_KEEPALIVE=1` | `HL_KEEPALIVE=0` | urllib, новый TLS на каждый вызов |
| Динамические чаевые (доля приза, кламп [5,1000] gwei, потолок по балансу) | `HL_TIP_MODE=auto` | `HL_TIP_MODE=off` | `HL_PRIORITY_GWEI` (0) |
| Параллельный залп sendRawTransaction | `HL_PARALLEL_BROADCAST=1` | `=0` | одиночный `HL_RPC` |
| Nonce prewarm (кэш chain-вида, 15с) | `HL_NONCE_PREWARM_SEC=15` | `=0` | живой RPC на пути выстрела |
| Кэш baseFee для fee-параметров (2.5с) | `HL_BASEFEE_CACHE_SEC=2.5` | `=0` | живой RPC на пути выстрела |
| Shadow-race телеметрия чужих ликвидаций | `HL_SHADOW=1` | `=0` | телеметрии нет |

### 2026-08-04: SPEC-FIRE — атомарный self-push + ликвидация («идем дальше» kelbic)
| Что | Флаг вкл. (деф.) | Откат |
|---|---|---|
| Спекулятивный выстрел liquidateWithPush по армленной кромке (свежая подписанная цена гейтвея даёт HF_est < порога при on-chain HF ≥ 1) | `HL_SPEC_FIRE=1` | `HL_SPEC_FIRE=0` + рестарт — реактивный путь не меняется вовсе (пуш к нему и так не цепляется) |
| Порог оценочного HF (запас 0.2% на дрейф долей) | `HL_SPEC_HF_FIRE=0.998` | поднять/опустить без рестарта кода — env + рестарт |
| Свежесть подписанного пакета | `HL_SPEC_MAX_AGE_MS=30000` | env + рестарт |
| Каденс вотчера гейтвея (hot при армленной кромке / cold) | `HL_SPEC_POLL_HOT=1.5` / `HL_SPEC_POLL_COLD=10` | env + рестарт |

Требует `HL_RAW_TX=1` и контракт v2 (гейтится в коде). Карта актив→фиды доказана on-chain
04.08 (bot/spec.py DRIVERS): пуш двигает цену пула 1:1; kHYPE/beHYPE/PT-*/USDHL/USR вне
карты — по ним spec не стреляет. Промах оценки = один реверт (HF-чек + min_profit контракта),
учитывается kill-switch'ем; повторы душит recently_fired.

### 2026-08-04 (вечер): SPEC-FIRE СНЯТ С БОЯ — форк-канарейка опровергла премиссу
| Что | Боевое значение | Почему |
|---|---|---|
| Спекулятивный self-push | `HL_SPEC_FIRE=0` в боевом env + дефолт в коде 0 | Пуш RedStone НЕ пермишенлесс: тот же payload от релейера принят, от нашего EOA молча скипнут (status=1, цена не движется) ⇒ выстрел = гарантированный реверт по HF |
| Порог девиации (второй рубеж) | `HL_SPEC_MIN_DEVIATION=0.0052` | Адаптер принимает апдейт только при \|Δцены\| >= 0.5% (замер по истории событий); ниже порога пуш — молчаливый no-op |

Включать обратно ТОЛЬКО при доказательстве, что наш адрес попал в список апдейтеров
(перепроверять тем же дифференциальным тестом на форке, он воспроизводим за 2 минуты).
